# 🖼️ Image Gallery

A responsive and interactive Image Gallery developed using **HTML, CSS, and JavaScript**.

This project is created as part of the **CodeAlpha Frontend Development Internship – Task 1**.

---

## 📌 Project Description

The Image Gallery allows users to view images based on different categories.

The gallery contains three main categories:

- 🏙️ City
- 🐾 Animals
- 🌿 Nature

Users can select a category to display only the related images.

Clicking on an image opens it in a larger **Lightbox view**, where users can navigate between images using **Next** and **Previous** buttons.

---

## ✨ Features

- 📸 Image Gallery
- 🏙️ City Image Category
- 🐾 Animals Image Category
- 🌿 Nature Image Category
- 🔍 Image Lightbox
- ⬅️ Previous Image Button
- ➡️ Next Image Button
- 🖱️ Hover Effects
- 📱 Responsive Design
